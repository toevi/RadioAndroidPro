💾 Playlist Management PRO

JSON Format - modern and easy

PRO version uses JSON format for playlist management. This means:

💾

Easy Backup

Save entire streams to a single file

✏️

App and Manual Edit

Edit playlist in notepad - JSON is human-readable

🤝

Easy Sharing

Share your favorite stations with friends with one file

JSON file example:

[{"Nazwa":"RMF","Sciezka":"http://rs201-krk.rmfstream.pl/rmf_fm"},{"Nazwa":"RAM","Sciezka":"http://stream.prw.pl:8000/rammp3"}]

Users can: copy the template, add their stations, change EQ settings and import the ready file to the app!
